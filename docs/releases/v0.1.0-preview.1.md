# v0.1.0-preview.1 — Automotive & Industrial Engineering Lab

**Prévia técnica, não uma plataforma industrial homologada.**

## Conteúdo desta prévia
- Catálogo e documentação de 111 projetos de análise de dados, SQL, BI, Machine Learning e automobilismo.
- Páginas de demonstração HTML estáticas com links adaptados ao GitHub Pages (`/portfolio/`), sitemap e metadados.
- Modelos e testes de domínio com **dados sintéticos**; exemplos executáveis em Python e laboratórios Streamlit/FastAPI executados localmente.
- Matriz de 111 projetos com lacunas e tecnologias atribuídas por projeto, não por grupo.

## Integridade e limitações
- GitHub Actions verifica a estrutura e regressões; passar no CI não valida desempenho de modelos com dados reais.
- F1-PIP #111 ainda possui escopo de modelos anunciado mas não implementado.
- Templates DAX/Power Query não são prova de Power BI Desktop rodando.
- Não há integração SAP/Ariba/MES/OT, telemetria FIA/FastF1 validada, FLIR ou ChassisSim.
- Imagens GHCR, quando publicadas, são **demonstrações de API** sem autenticação de produção, sem credenciais e sem modelos reais embutidos.

## Artefatos de release
- `portfolio-pages-preview.zip`: site estático gerado e preparado para o caminho de projeto do Pages.
- `TECHNOLOGY_GAP_MATRIX_INTEGRATED.csv`: auditoria de tecnologia por projeto.
- Código-fonte e testes estão no repositório GitHub, vinculados ao commit da tag.
