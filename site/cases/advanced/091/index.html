Industrial · Sistemas ponta a ponta · Projeto #091

Motor End-to-End de Governança e Risco de Fornecedores

Arquitetura completa integrando dados financeiros, compliance jurídico (LGPD/SOX) e scoring.

Transparência: apenas dados sintéticos. Kafka requer broker ativo e CI separado; DAX não executado. Não existe integração SAP, controle industrial, acesso a pessoas reais, segurança de produção ou impacto econômico comprovado.

Executar o pipeline

python -m pip install -r requirements/advanced.txt
python projetos/10-advanced/091-end-to-end-vendor-governance-risk-engine/main.py --save
uvicorn advanced_batch.api:app --host 127.0.0.1 --port 8000
Validação apenas para métricas sobre fixtures geradas localmente. É necessária homologação externa antes de aplicações empresariais.
