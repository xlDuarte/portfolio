Industrial · BI e finanças · Projeto #083

Análise de Retorno de Iniciativas Comerciais e Feiras B2B

Avaliação de custo de aquisição, conversão de cotações técnicas e margem gerada.

Limites: ERP e indicadores totalmente fictícios, sem SAP/Ariba, desempenho financeiro real, relatório Power BI Desktop testado ou conformidade regulatória comprovada.

Pipeline auditável

Consulta SQL realmente executada em SQLite, cálculo Python/Pandas específico, relatório JSON e visualização Matplotlib. Arquivos Power Query/DAX disponíveis como templates editáveis, não executados por CI.

Reprodução

python -m pip install -r requirements/business.txt
python projetos/09-business/083-b2b-commercial-campaign-roi-analysis/main.py --save
python -m streamlit run business_batch/app.py
Revisão humana obrigatória para análise financeira, seleção de investimentos e conformidade.
