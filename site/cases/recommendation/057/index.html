Industrial · Recomendação · Projeto #057

Feed Personalizado de Inteligência de Commodities e Setor

Curadoria automatizada de boletins sobre aço, energia, frete marítimo e regulação.

Limitação: dados e identificadores sintéticos, sem validação em produção, integração corporativa ou impacto econômico comprovado. As saídas são sugestões para revisão humana.

Motor real

Consulta reproduzível sobre fixtures locais com regras de negócio do domínio.

Reprodução local

python -m pip install -r requirements/recommendation.txt
python projetos/06-recommendation/057-industrial-market-intelligence-feed/main.py --query "steel logistics energy"
python -m streamlit run projetos/06-recommendation/057-industrial-market-intelligence-feed/streamlit_app.py
Os resultados de dados sintéticos não são avaliações independentes de relevância ou confiabilidade.
