Forecasting · Projeto #67

Machining Center & Dock Slot Forecast

Ocupação semanal de docas e usinagem simulada

Limite: série e alvos 100% sintéticos. Nenhuma métrica industrial ou benefício financeiro foi observado. Intervalos não calibrados em dados reais.

Treino e validação

240 semanas artificiais; três janelas walk-forward, 8 semanas por origem. Baseline sazonal e Statsmodels ETS com seleção apenas por validação; Prophet treinado de fato como diagnóstico separado no teste. Gráficos em Plotly exportados localmente. Métricas MAE, RMSE, sMAPE, MAPE e WAPE.

Execução reproduzível

python -m pip install -r requirements-timeseries.txt
python projetos/07-timeseries/067-machining-center-dock-slot-forecast/main.py --save
python projetos/07-timeseries/067-machining-center-dock-slot-forecast/main.py --future --save

Código Python ↗ · Metodologia e limitações ↗

Sem generalização validada para dados não sintéticos; seleção de modelos usa validação temporal, nunca o teste final.
