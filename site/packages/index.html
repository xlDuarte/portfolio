GitHub Packages (GHCR)

O portfólio prevê duas imagens versionadas após release e testes de build reais:

ghcr.io/xlduarte/industrial-analytics-api-demo

FastAPI para eventos industriais fictícios, SQLite local e dados sintéticos. O endpoint HTTP não é um sistema empresarial seguro.

ghcr.io/xlduarte/motorsport-mlops-api-demo

API FastAPI de inferência para experimentos MLflow. A imagem não inclui pesos treinados: é necessária a configuração de um artefato de modelo.

Não são imagens certificadas para produção. Publicação depende do workflow GHCR e da autorização do GitHub. Pacotes privados só aparecem para contas autorizadas.
