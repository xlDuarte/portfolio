O que é verificado

Cada alteração no repositório roda a suíte automatizada no GitHub Actions: catálogo dos 111 projetos, execução dos algoritmos sobre as bases de teste, contratos de API e SQL, treinos curtos e as páginas deste site.

O que não é afirmado

Os testes mostram que o código faz o que diz. Não mostram desempenho em dados de uma empresa, operação segura de equipamentos ou ganho financeiro. A matriz de evidências separa, projeto a projeto, o que foi feito do que não foi.
