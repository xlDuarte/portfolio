Método e transparência

Cada projeto separa o que foi calculado do que seria preciso para uma validação real. Bases sintéticas são geradas com semente fixa e identificadas na página. Nenhum projeto usa dado confidencial de empresas onde trabalhei.

Os números do catálogo industrial vêm de exercícios por técnica; os estudos de caso completos e os projetos de Fórmula 1 são os trabalhos mais profundos.

Versões e pacotes

O repositório publica pré-releases técnicas e duas imagens de demonstração no GitHub Container Registry: uma API de eventos industriais fictícios e uma API de inferência para os experimentos com MLflow. Não são produtos certificados.
