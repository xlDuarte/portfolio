# Auditoria técnica do portfólio — 21/10/2026

**Escopo:** `xlDuarte/portfolio`, 111 projetos Python em 11 categorias, interface SPA, protótipo F1-PIP e deployment Vercel.

## Verificações reproduzíveis realizadas

- Pacote-base auditado: 238 arquivos.
- Catálogo: 111 identificadores únicos 001–111; cada projeto tem `main.py` e `README.md` na pasta correspondente.
- 113 arquivos Python do pacote original passaram por análise sintática (`ast.parse`).
- **111/111** `main.py` passaram em smoke test por subprocesso com timeout. Isto **não comprova precisão, desempenho preditivo ou integrações externas**.
- Cinco páginas HTML passaram por verificação sintática dos scripts JavaScript embutidos (`node --check`).
- 109/111 protótipos exibem sinais de dados sintéticos ou execução simulada; nenhum dataset/imagem real foi incluído no pacote original.
- Prova de conceito F1: bloqueios de *look-ahead* nos dados de treino e snapshots foram testados com cenários sintéticos.
- Detector heurístico simples não encontrou padrões comuns de segredos no pacote; não substitui auditoria de segurança abrangente.

## Problemas identificados e correções

| Severidade | Achado | Ação |
|---|---|---|
| P1 | Links de projetos apontavam para repositório inexistente/antigo | Corrigido para `xlDuarte/portfolio/tree/main/projetos` |
| P1 | Comando `git clone` mostrava endereço incorreto | Corrigido |
| P1 | Interface chamava código gerado de `main.py` real e resumos gerados de `README.md` real | Rótulos alterados e links explícitos aos arquivos originais no GitHub |

| P1 | Pipeline não executava testes antes da publicação | Inclusão de 6 testes independentes de bibliotecas externas, executando 111 scripts |
| P2 | README título informava 110 projetos | Corrigido para 111 |

## Limitações — pendências para aceite integral

1. Os 111 projetos são predominantemente protótipos sintéticos; não há validação de modelos contra datasets reais, métricas auditadas, test coverage por função ou integração com sistemas de manufatura.
2. As páginas individuais são rotas de SPA por fragmento (`#/projetos/categoria/id`); não existem 111 HTMLs pré-renderizados independentes com metadados SEO próprios.
3. O módulo F1-PIP está parcial; nomes de modelos não significam treinamento efetivo de modelos de terceiros.
4. Abertura e interação do site ao vivo, inclusive layout responsivo e console JavaScript do navegador, não puderam ser executadas neste ambiente: acesso HTTP externo e navegador automatizado foram bloqueados.
5. Estado do workflow de GitHub Actions e deploy automático em futuros pushes exige verificação própria. O deployment Vercel pode ser inspecionado por seu ID/commit.
6. O repositório estava configurado como **privado** na consulta de auditoria. Links corretos a `main.py` e `README.md` exigem autenticação GitHub para visitantes sem acesso.
